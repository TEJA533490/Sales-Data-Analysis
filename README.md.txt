# Sales Data Analysis & Power BI Dashboard

## Project Overview
This project analyzes retail sales data to identify revenue trends, seasonal patterns, and top-performing products.  
Python was used for data cleaning and analysis, and Power BI was used for visualization.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Excel
- Power BI

## Dataset
- Raw sales data was cleaned using Python
- Cleaned data exported as `cleaned_sales_data.csv`
- The cleaned CSV file is connected to Power BI

## Steps Followed
1. Loaded raw sales dataset into Python
2. Cleaned data (handled missing values, duplicates, date formats)
3. Performed Exploratory Data Analysis (EDA)
4. Visualized trends using Matplotlib
5. Exported cleaned data to CSV
6. Connected cleaned data to Power BI
7. Built an interactive dashboard with KPIs

## Power BI Dashboard
The dashboard includes:
- Total Sales
- Monthly Revenue Trends
- Sales by Category
- Top Performing Products

## Outcome
This project enables quick business insights through clear visual storytelling and interactive dashboards.
